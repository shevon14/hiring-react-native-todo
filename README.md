# React Native Take-home Assignment — "tasked"

## 🚀 **Description**  
This project implements a Todo Task Manager assessment using React Native (Expo).

Key features delivered:
- Implemented task creation with inline input box
- Added toggle functionality for marking tasks complete/incomplete
- Implemented editing of existing tasks
- Added long-press delete with confirmation alert
- Integrated local persistence using AsyncStorage
- Added UI animations (checkbox press & list item fade-in) using Reanimated
- Implemented reducer-based state logic for predictable updates
- Added Empty Input Guard (prevents saving blank tasks)
- Fully responsive FAB that adapts when keyboard opens

---

## 🛠️ **Setup** 

### Install dependencies

```bash
npm install
```
Or using yarn:

```bash
yarn install
```

### Running the App (iOS and Android)

```bash
npm run ios
```
```bash
npm run android
```
